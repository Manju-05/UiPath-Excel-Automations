# UiPath Excel Automations

A collection of UiPath RPA (Robotic Process Automation) projects designed to automate Excel data manipulation, processing multiple Excel files, and managing employee data workflows.

---

## 📌 Project Overview

This repository contains workflows demonstrating various Excel automation techniques using UiPath Studio:

* **Excel Automations:** Demonstrates foundational and advanced Excel data manipulation techniques.
* **Employee Data Automation:** Handles processing, filtering, and organizing employee record datasets.
* **Multiple Excel File Automation:** Automates reading, combining, and processing data across multiple Excel workbooks simultaneously.
